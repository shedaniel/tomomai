## Games

All game data lives under `/api/v1/games/{game}`. Use canonical `maimai` or
`chunithm`. Aliases and omitted game IDs are invalid. Successful JSON responses include `game`.

`/api/v1/me`, `/api/v1/me/settings`, `/api/v1/me/scopes`, and `/api/v1/ok` are global.

Catalog routes include `/games/{game}/parents`, `/games/{game}/songs/versions`,
`/games/{game}/songs`, and `/games/{game}/songs/{id}`. The song catalog requires
both `region` and `gameVersion`; use the versions endpoint to discover them.
Catalog type/difficulty and score combo/sync/clear statuses are game-specific
integer codes, which [`/games/{game}/codes`](/developer/reference/get-games-game-codes)
lists. Scores expose `scoreValue` and `secondaryScore`. The
[changelog](/developer/guides/changelog) maps the fields of the earlier
maimai-only API to these.

Unknown games and unavailable regions return HTTP 400 with `UNKNOWN_GAME` or
`UNSUPPORTED_REGION`. Disabled games and unsupported capabilities return
HTTP 422 with `GAME_NOT_ENABLED` or `UNSUPPORTED_CAPABILITY`.

## Regions

User-data endpoints (`/snapshots`, `/snapshots/latest`, `/snapshots/{id}`,
`/recents`, `/stats`, `/albums`) require a `?region=` query parameter.
Valid values:

- `intl` — international
- `jp` — Japan
- `cn` — China

A user can have data across multiple regions; tomomai will not silently
pick one for you.

## Pagination

`/recents` and `/albums` accept `?limit=` and `?offset=`:

- `limit` defaults to 50 for recents, 20 for albums. Max 100 for both.
- `offset` defaults to 0.

Responses include `hasMore: boolean`. Recents additionally returns
`totalCount` so you can render a position indicator. Albums returns only
`hasMore` — counting all albums up front would be expensive.

```bash
# Page 2 of recents (50 items per page)
curl "https://tomomai.lol/api/v1/games/maimai/recents?region=intl&limit=50&offset=50" \
  -H "Authorization: Bearer tmk_…"
```
