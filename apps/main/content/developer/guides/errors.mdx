All `/api/v1/*` errors return JSON of the shape `{ "error": "..." }`. Errors
with a stable cause also carry a machine-readable `code`, such as
`INVALID_PARAMETER` or `UNSUPPORTED_CAPABILITY`.

| Status | Meaning | What to do |
|---|---|---|
| `400` | Bad request. A path or query parameter is missing or invalid (`INVALID_PARAMETER`), the game is unknown (`UNKNOWN_GAME`) or the region is not served (`UNSUPPORTED_REGION`). | Read the error message; fix the request. |
| `401` | Missing API key — no `Authorization` / `x-api-key` header. | Add a token. |
| `403` | Token is malformed, revoked, expired, or doesn't hold a required scope. | Re-auth (OAuth) or rotate the key (API key). |
| `404` | Resource not found (e.g. snapshot ID doesn't belong to you). | Don't retry; double-check the path. |
| `410` | The path moved under `/api/v1/games/{game}` (`MOVED`). The body's `location` is the new path. | Send the request to `location` and apply the [changelog](/developer/guides/changelog)'s field changes. |
| `422` | The game is not enabled on this deployment (`GAME_NOT_ENABLED`) or does not offer this endpoint (`UNSUPPORTED_CAPABILITY`). | Don't retry. The endpoint reference lists the games each endpoint serves. |
| `500` | Server error. | Retry with exponential backoff. If persistent, file an issue. |

## OAuth-specific errors

OAuth errors come from `/api/auth/oauth2/*` and follow
[RFC 6749 §5.2](https://datatracker.ietf.org/doc/html/rfc6749#section-5.2)
(`invalid_request`, `invalid_client`, `invalid_grant`, etc.). The
authorization server redirects errors back to your `redirect_uri` with
`?error=…&error_description=…`.

## Rate limiting

tomomai applies a three-layer rate-limit model to `/api/v1/*` (per-key
burst, per-user umbrella burst, and a monthly quota), plus a coarse per-IP
limit on all `/api/*` traffic. A blocked request returns
`429 Too Many Requests` with a `Retry-After` header — wait at least that
many seconds before retrying.

See the [Rate limits guide](/developer/guides/rate-limits) for the limits,
the response headers you can read to self-throttle, and per-endpoint cost
units.
